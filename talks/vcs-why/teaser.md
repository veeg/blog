The talk features a walkthrough of Version Control Systems (VCS), predominantly Git, and the software development
practices the industry has gravitated towards. There will be both historical facts, fun facts, and highly subjective
opinions (facts) on "The Right Way" to use git. Throughout the fact dropping mission, tidbits of Git features and how to
use Git effectively at scale will be interspersed. We will expand on all the value added services outside of Git we now
require as part of our modern development workflows. Lastly, we may even take a peek into how LLM-driven autonomous
agents impact this workflow, and how this new era calls for even more rigorous practices around development workflows.
